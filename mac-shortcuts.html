Mac Shortcuts

Excel keyboard shortcuts for Mac users — including what's different when working via Windows VPN.

💡 Mac on Windows VPN? The biggest gotchas: (1) F-keys need Fn on Mac — e.g., F4 for absolute refs becomes Fn+F4. (2) The Alt key Ribbon navigation from Windows doesn't exist on Mac — use the menu bar instead. (3) Home/End keys on Mac use Fn+Arrow. (4) Many shortcuts swap Ctrl → ⌘ (Command).
⌘ vs Ctrl

Most Windows Ctrl shortcuts become ⌘ on Mac. E.g., Ctrl+C → ⌘+C.

F-Key Mystery

Mac F-keys control brightness/volume by default. Hold Fn to send F-keys to Excel. Or change it in System Settings → Keyboard.

No Alt Ribbon Nav

Windows Alt key shows Ribbon shortcut letters. This doesn't exist on Mac. Use the top menu bar instead.

Home / End Keys

Most Mac keyboards don't have Home/End. Use Fn+← and Fn+→.

Delete vs Backspace

Mac Delete = Windows Backspace (deletes backward). For forward delete: Fn+Delete.

AutoSum Gotcha

Windows Alt+= doesn't work on Mac. Use ⌘+Shift+T instead.
