Macros & Basic VBA

Advanced ⏱ 10 min read

Automate repetitive tasks with one click using macros and introductory Visual Basic for Applications (VBA).

💡 What It Is & Why It Matters

Macros let you record a sequence of actions and replay them with one click — perfect for repetitive formatting, data cleaning, or report generation. VBA (Visual Basic for Applications) is the programming language behind macros, and knowing the basics unlocks powerful automation.

📋 Before You Start

  • You need to enable the Developer tab. Go to File → Options → Customize Ribbon → check Developer → OK.
  • On Mac: Excel → Preferences → Ribbon & Toolbar → check Developer.

🚀 Step-by-Step

  1. 1
    Record a macro
    Go to Developer → Record Macro (or View → Macros → Record Macro). Give it a name (no spaces), assign an optional shortcut key (e.g., Ctrl+Shift+F), and choose where to store it (This Workbook for this file only, Personal Macro Workbook to use in any workbook). Click OK — recording begins.
  2. 2
    Perform your actions
    Do the steps you want to automate: format cells, apply filters, copy/paste, sort data. Keep it focused — every action is recorded.
  3. 3
    Stop recording
    Click Developer → Stop Recording (or the Stop button in the status bar). Your macro is saved.
  4. 4
    Run the macro
    Go to Developer → Macros → select your macro → Run. Or use the keyboard shortcut you assigned.
  5. 5
    View the VBA code
    Go to Developer → Visual Basic (or Alt+F11 on Windows, Option+Fn+F11 on Mac). In the Project Explorer, open Modules → Module1. You'll see the VBA code Excel generated.
  6. 6
    Edit the macro
    You can modify the code directly. Common edits: change a hardcoded range to a dynamic one, add a loop, change a color value. Key concepts include Sub (procedure), Range("A1"), Cells(row,col), ActiveSheet, and Selection.
  7. 7
    Add a button to run the macro
    Go to Insert → Shapes, draw a shape, right-click → Assign Macro → select your macro. Now clicking the shape runs the macro.
  8. 8
    Write a simple VBA sub
    In the VBA editor, click Insert → Module, then type: 
    Sub FormatHeaders()
    Range("A1:E1").Font.Bold = True
    Range("A1:E1").Interior.Color = RGB(33, 163, 102)
    Range("A1:E1").Font.Color = RGB(255, 255, 255)
End Sub
  9. 9
    Macro security settings
    Go to File → Options → Trust Center → Trust Center Settings → Macro Settings. Use 'Disable all macros with notification' — Excel will ask before running. Never use 'Enable all macros'.

⭐ Pro Tips

💡
Relative References
Use relative references when recording (Developer → Use Relative References) so the macro works on any selected range, not just the recorded one.
ℹ️
Global Macros
Store frequently-used macros in the Personal Macro Workbook so they're available in every Excel file you open.
💡
Dynamic Coding
Record a basic version, then hand-edit the VBA to make it dynamic (replace fixed ranges with variables). Add MsgBox "Done!" at the end to confirm completion. Use F8 in the VBA editor to step through code line by line for debugging.

⚠️ Common Mistakes

  • Absolute cell references
    Macro only works on specific recorded cells.
    Fix: enable 'Use Relative References' before recording, or edit the VBA.
  • Macro not visible
    Stored in the wrong workbook.
    Fix: check the Store In setting; use Personal Macro Workbook for always-available macros.
  • Macros lost
    File saved without macro support.
    Fix: always save as .xlsm (Excel Macro-Enabled Workbook) not .xlsx.
  • Running an unknown macro
    Security risk from running code off the internet.
    Fix: only run macros from trusted sources and keep 'Disable with notification' checked.
