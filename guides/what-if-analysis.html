What-If Analysis

Advanced ⏱ 8 min read

Explore how changes to inputs affect your results — without manually editing cells. Excel has 3 tools: Goal Seek, Data Tables, and Scenario Manager.

💡 What It Is & Why It Matters

What-If Analysis lets you explore how changes to inputs affect your results — without manually editing cells. Excel has 3 tools: Goal Seek (work backwards from a target), Data Tables (test multiple inputs at once), and Scenario Manager (compare named sets of assumptions).

📋 Before You Start

  • A basic financial or mathematical model set up with formulas linking dependent inputs and outputs.
  • Familiarity with absolute references to lock formula cells correctly.

🚀 Step-by-Step

Goal Seek

  1. 1
    Set up a formula
    You need a formula whose result you want to hit a specific target. E.g., a loan payment formula =PMT(B1/12, B2, B3) in cell B4.
  2. 2
    Run Goal Seek
    Go to Data → What-If Analysis → Goal Seek. Set Cell: your result cell (B4). To Value: the target result (e.g., -1500). By Changing Cell: the input to adjust (e.g., B3 = loan amount). Click OK.
  3. 3
    Read the result
    Excel iterates to find the input value that produces your target. The changing cell updates with the solution. Click OK to keep or Cancel to revert.

Data Tables

  1. 4
    One-variable data table
    Set up a column of input values (e.g., interest rates from 3% to 8%). In the row above the first input (one column to the right), reference your formula. Select the input column + formula cell. Go to Data → What-If Analysis → Data Table. Row input cell: blank. Column input cell: the original input cell. Click OK.
  2. 5
    Two-variable data table
    Set up a row of one input (e.g., loan terms) and a column of another (e.g., interest rates). Put the formula at their intersection. Select the whole block. Data → What-If Analysis → Data Table. Row input: cell for row values. Column input: cell for column values.

Scenario Manager

  1. 6
    Create scenarios
    Go to Data → What-If Analysis → Scenario Manager → Add. Name the scenario (e.g., 'Best Case'), choose the changing cells (the assumptions that vary). Enter values for each cell.
  2. 7
    Add more scenarios
    Click Add again: 'Base Case', 'Worst Case', etc. Each scenario stores its own set of input values.
  3. 8
    View and compare
    Select a scenario → Show to see its results in your model. Click Summary to generate a Scenario Summary table comparing all scenarios side by side.

⭐ Pro Tips

ℹ️
Multiple Variables? Use Solver Goal Seek only works with a single changing cell — for multiple variables use Solver.
⚠️
Data Table Array Formulas Data Tables create array formulas — you can't edit individual cells; delete all results and rebuild if you need changes.
💡
Presenting to Clients Use Scenario Manager for client presentations — create Best/Base/Worst cases and show the summary table.
💡
Protect Your Scenarios Protect the Scenario Manager: Tools → Protection → Protect Workbook → Scenarios to prevent others from editing your scenarios.
⚠️
Always Save Before Goal Seek Save your model BEFORE running Goal Seek in case you want to revert easily.

⚠️ Common Mistakes

  • Goal Seek can't find a solution
    The target is mathematically impossible given the formulas.
    Fix: check formula logic and widen the target bounds.
  • Data table returns all zeros
    Formula not referencing the correct input cell.
    Fix: ensure the formula uses the exact cell specified in the dialog.
  • Scenario Manager shows #REF
    Changing cells were deleted or moved.
    Fix: edit the scenario and re-select the correct cells.
