Dynamic Arrays

Intermediate ⏱ 7 min read

Master dynamic array functions like FILTER, SORT, and UNIQUE that automatically spill results across cells.

💡 What It Is & Why It Matters

Dynamic array formulas (available in Microsoft 365 and Excel 2021+) can return multiple results that automatically 'spill' into neighboring cells. Functions like FILTER, SORT, UNIQUE, SEQUENCE, SORTBY, and RANDARRAY replace many complex older approaches.

📋 Before You Start

  • You need Microsoft 365, Excel 2021, or Excel for the web.
  • Neighboring cells must be empty for results to spill properly.

🚀 Step-by-Step

  1. 1
    Understand spill behavior
    When a dynamic array formula returns multiple values, they automatically fill (spill) into adjacent cells. You only enter the formula once, in the top-left cell. Neighboring cells must be empty or you'll get a #SPILL! error.
  2. 2
    UNIQUE
    Returns a list of unique values from a range. =UNIQUE(A2:A100) returns one of each value. =UNIQUE(A2:A100,,TRUE) returns values that appear exactly once.
  3. 3
    SORT
    Returns a sorted copy of a range. =SORT(A2:B20) sorts by first column A-Z. =SORT(A2:B20, 2, -1) sorts by 2nd column descending (-1=descending, 1=ascending).
  4. 4
    SORTBY
    Sorts a range by one or more other ranges (not part of the sorted data). =SORTBY(A2:B20, C2:C20, -1) sorts A:B by the values in column C descending.
  5. 5
    FILTER
    Returns rows that match a condition. =FILTER(A2:C20, B2:B20="East") returns only rows where column B is 'East'. =FILTER(A2:C20, B2:B20="East", "No results") adds a fallback.
  6. 6
    FILTER with multiple conditions
    Use * for AND: =FILTER(A2:C20, (B2:B20="East")*(C2:C20>100)) — returns rows where B=East AND C>100. Use + for OR: (B2:B20="East")+(B2:B20="West").
  7. 7
    SEQUENCE
    Generates a list of sequential numbers. =SEQUENCE(10) gives 1-10. =SEQUENCE(5,3) gives a 5-row by 3-column grid. =SEQUENCE(12,1,DATE(2025,1,1),30) gives 12 monthly dates.
  8. 8
    RANDARRAY
    Generates random numbers. =RANDARRAY(10) gives 10 random decimals. =RANDARRAY(5,3,1,100,TRUE) gives a 5×3 grid of random integers between 1 and 100.
  9. 9
    Reference the spill range
    Use the # operator to reference all spilled results: if your UNIQUE formula is in E2, use =SORT(E2#) to sort all its spilled results. This is a spill range reference.
  10. 10
    Combine functions
    Nest them: =SORT(UNIQUE(A2:A100)) to get a sorted unique list. =FILTER(A2:C20, ISNUMBER(MATCH(B2:B20, E2#, 0))) to filter using a dynamic list.

Function Comparison

Function What it does Example
UNIQUE Deduplicate a list =UNIQUE(A2:A100)
SORT Sort a range =SORT(A2:B20, 2, -1)
SORTBY Sort by external column =SORTBY(A2:B20, C2:C20)
FILTER Filter rows by condition =FILTER(A:C, B:B>100)
SEQUENCE Generate number series =SEQUENCE(10)
RANDARRAY Random number array =RANDARRAY(10,1,1,100,TRUE)

⭐ Pro Tips

💡
Dropdown Validation
Use UNIQUE+SORT to build auto-updating dropdown list sources for data validation.
💡
Replace Complex Formulas
Use FILTER to replace messy helper columns and complicated VLOOKUP or INDEX/MATCH array combinations.
ℹ️
Chaining and Counting
The # spill operator makes dynamic arrays chainable, like =SORT(UNIQUE(A2:A100)). Use =COUNTA(E2#) to count how many results a spill formula returned.
⚠️
Avoid #CALC! Errors
FILTER with no match returns #CALC! — always add the 3rd argument (fallback value) to handle empty results gracefully.

⚠️ Common Mistakes

  • #SPILL! error
    Cells in the spill range are occupied.
    Fix: clear all cells in the expected spill range.
  • #CALC! error
    FILTER found no matches and you didn't provide a fallback.
    Fix: add 3rd argument: =FILTER(A:C, B:B>100, "No results").
  • Formula not available
    You are using Excel 2019 or older, which doesn't support these functions.
    Fix: use XLOOKUP or legacy Ctrl+Shift+Enter array formulas as alternatives.
  • Editing spilled cells
    You can't edit non-anchor spill cells (they are grayed out or show errors when edited).
    Fix: edit only the top-left anchor cell containing the formula.
