Power Query

Advanced ⏱ 10 min read

Automate your data import and transformation workflow without writing formulas.

💡 What It Is & Why It Matters

Power Query (called 'Get & Transform' in Excel) lets you import data from dozens of sources (CSV, web, databases, other workbooks) and clean/transform it automatically — without writing formulas. Every transformation is recorded as a step you can edit or replay.

📋 Before You Start

  • Power Query is available in Excel 2016+.
  • On Mac, some features are limited — most import/transform steps work, but some connectors (SQL Server, SharePoint) may require Windows.

🚀 Step-by-Step

  1. 1
    Open Power Query
    Go to Data → Get Data → choose your source: From File (CSV, Excel, JSON), From Web (URL), From Database, or other sources. For a CSV: Data → Get Data → From File → From Text/CSV.
  2. 2
    Preview and load
    Power Query shows a preview. Check that data looks correct, then click Transform Data (to clean first) or Load (to import as-is).
  3. 3
    The Power Query Editor
    The editor has a ribbon at top, your data preview in the center, and a 'Query Settings' panel on the right showing Applied Steps — every change you make is recorded here.
  4. 4
    Remove unnecessary columns
    Select columns to keep (Ctrl+click), then right-click → Remove Other Columns. Or right-click unwanted columns → Remove.
  5. 5
    Rename columns
    Double-click a column header to rename it. Use clear, consistent names.
  6. 6
    Change data types
    Click the data type icon in the column header (ABC for text, 123 for number, calendar for date). Setting the correct type is critical — dates stored as text won't work in formulas.
  7. 7
    Filter rows
    Click the dropdown arrow in a column header to filter out unwanted values (blanks, errors, specific text).
  8. 8
    Split, merge, or transform text
    Use the Transform tab: Split Column (by delimiter or character count), Merge Columns, Extract (first N chars, text before/after delimiter), Trim/Clean.
  9. 9
    Group and summarize
    Transform → Group By to aggregate: sum sales by region, count orders by category, etc. This replaces complex SUMIFS formulas.
  10. 10
    Close & Load
    When done, click Home → Close & Load → Close & Load To... Choose Table in a new or existing sheet, or add to the Data Model.
  11. 11
    Refresh the query
    When source data updates, go to Data → Refresh All (or right-click the query table → Refresh). All transformations re-apply automatically.

⭐ Pro Tips

💡
Rename Steps Rename your Applied Steps to describe what each step does — makes the query maintainable.
ℹ️
Append vs Merge Use Append Queries (Home → Append Queries) to stack multiple files/sheets into one table. Use Merge Queries (Home → Merge Queries) for a VLOOKUP-style join between two tables.
⚠️
Undo Steps Right-click an Applied Step → Delete to undo a specific transformation without losing the others.
💡
Clean Once, Refresh Forever Use Power Query to clean a messy CSV once, then just Refresh to re-run all cleaning automatically on new data.

⚠️ Common Mistakes

  • Skipping data type assignment
    Dates/numbers are treated as text and break formulas downstream.
    Fix: always set types in step 6.
  • Hardcoding a file path
    Query breaks when file moves to a new folder.
    Fix: use a parameter for the file path.
  • Too many Applied Steps
    The query becomes slow to evaluate.
    Fix: combine similar steps (e.g., multiple filter steps into one).
  • Loading to wrong location
    Table lands on wrong sheet or creates unnecessary data duplicates.
    Fix: use Close & Load To... to specify the exact destination.
