VLOOKUP vs XLOOKUP

Beginner ⏱ 6 min read

Learn the difference between Excel's classic lookup function and its modern, powerful replacement.

💡 What It Is & Why It Matters

VLOOKUP has been Excel's go-to lookup formula for 30+ years, but it has significant limitations. XLOOKUP (available in Microsoft 365 and Excel 2021+) fixes all of them. This guide walks you through both so you know which to use — and when.

📋 Before You Start

  • You need Excel 365 or Excel 2021 or newer to use XLOOKUP.
  • Basic knowledge of Excel formulas is recommended.

🚀 Step-by-Step

  1. 1
    Understand VLOOKUP
    VLOOKUP searches the FIRST column of a table and returns a value from a column to the RIGHT. Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]). Always use FALSE for exact match.
  2. 2
    Build a VLOOKUP
    Click your result cell. Type =VLOOKUP( then: click the lookup cell (e.g. A2), add a comma, select the lookup table (e.g. D:F), add a comma, type the column number to return (e.g. 2 for the 2nd column), add a comma, type FALSE, close the bracket. Example: =VLOOKUP(A2, D:F, 2, FALSE)
  3. 3
    Understand VLOOKUP's limits
    (1) Can only look LEFT to RIGHT. (2) Column number breaks if you insert columns. (3) Returns first match only. (4) Slower on large datasets.
  4. 4
    Understand XLOOKUP
    XLOOKUP is more flexible: it looks in any direction, returns entire arrays, handles errors natively, and uses column references (not index numbers). Syntax: =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
  5. 5
    Build an XLOOKUP
    Type =XLOOKUP( then: click the lookup cell (e.g. A2), add a comma, select just the lookup COLUMN (e.g. D:D), add a comma, select the return COLUMN (e.g. E:E), add a comma, type "Not found" for the error fallback. Example: =XLOOKUP(A2, D:D, E:E, "Not found")
  6. 6
    Return multiple columns with XLOOKUP
    Select the return_array as multiple columns (e.g. E:G) and XLOOKUP will spill all three columns automatically. VLOOKUP cannot do this.
  7. 7
    Wrap VLOOKUP with IFERROR
    Since VLOOKUP doesn't have a built-in not-found message, wrap it: =IFERROR(VLOOKUP(A2, D:F, 2, FALSE), "Not found")
  8. 8
    When to still use VLOOKUP
    Use VLOOKUP when sharing files with colleagues who have Excel 2019 or earlier (XLOOKUP won't work for them).
Feature VLOOKUP XLOOKUP
Direction Left to right only Any direction
Error handling Needs IFERROR wrapper Built-in 4th argument
Column reference Number (fragile) Direct range (robust)
Multiple columns One at a time Returns array
Compatibility All versions 365 / Excel 2021+
Speed Slower Faster

⭐ Pro Tips

💡
Exact Matches Always use FALSE (exact match) in VLOOKUP unless you're doing range lookups on sorted data.
ℹ️
XLOOKUP Match Mode XLOOKUP's 5th argument match_mode: 0=exact, -1=exact or next smaller, 1=exact or next larger, 2=wildcard.
ℹ️
XLOOKUP Search Mode XLOOKUP's 6th argument search_mode: 1=first to last, -1=last to first (finds LAST match!).
💡
INDEX+MATCH Use INDEX+MATCH as a VLOOKUP alternative if you can't use XLOOKUP.
💡
Look Upwards Use XLOOKUP to look UP (not just right) — e.g., find a row header from a value in the middle of a dataset.

⚠️ Common Mistakes

  • Using TRUE in VLOOKUP
    Using TRUE (approximate match) when you need an exact match often returns wrong results.
    Always use FALSE for exact matches.
  • VLOOKUP Column Index Broken
    VLOOKUP col_index breaks if you insert a column in the table, returning wrong data.
    Switch to XLOOKUP or INDEX+MATCH.
  • XLOOKUP Returns #N/A
    The lookup value was not found in the range.
    Add the 4th argument to XLOOKUP: "Not found".
  • Forgetting to Lock Ranges
    Reference shifts when copying the formula down, leading to missed matches.
    Use absolute refs like D$1:$F$100 or full columns D:F.

📌 Quick Reference

Cheat Sheet
VLOOKUP =VLOOKUP(A2, D:F, 2, FALSE)
VLOOKUP safe =IFERROR(VLOOKUP(A2, D:F, 2, FALSE), "Not found")
XLOOKUP =XLOOKUP(A2, D:D, E:E, "Not found")
