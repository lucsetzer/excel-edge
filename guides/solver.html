Solver

Advanced ⏱ 8 min read

Find optimal values for formula cells by adjusting other cells subject to constraints you define.

💡 What It Is & Why It Matters

Solver is an Excel add-in that finds the optimal value for a formula cell by adjusting other cells — subject to constraints you define. It's used for resource allocation, scheduling, portfolio optimization, pricing, and any problem where you want to maximize or minimize an outcome within limits.

📋 Before You Start

  • Solver must be enabled. Go to File → Options → Add-ins → Manage: Excel Add-ins → Go → check Solver Add-in → OK.
  • On Mac: Tools → Excel Add-ins → check Solver → OK.
  • Then find Solver on the Data tab.

🚀 Step-by-Step

  1. 1
    Set up your model
    Create a spreadsheet with: (a) Decision variable cells (the cells Solver will change — e.g., how many of each product to make), (b) Constraint cells (limits — e.g., available hours, budget), (c) Objective cell (the formula to optimize — e.g., =SUMPRODUCT(B2:B5, C2:C5) for total profit).
  2. 2
    Open Solver
    Go to Data → Solver.
  3. 3
    Set the Objective
    In 'Set Objective', click the cell containing your target formula (the value to maximize, minimize, or hit a specific target). Select Max, Min, or Value Of.
  4. 4
    Set the variable cells
    In 'By Changing Variable Cells', select the decision variable cells (the ones Solver should adjust). These must be referenced by the objective formula.
  5. 5
    Add constraints
    Click Add. Set a cell reference (e.g., B2), choose a relationship (<=, >=, =, int, bin), and enter the constraint value or cell. Common constraints: decision variables >= 0, total resources <= available.
  6. 6
    Choose a solving method
    GRG Nonlinear: for smooth nonlinear problems. Simplex LP: for linear problems (most common for resource allocation). Evolutionary: for non-smooth problems. For most business problems, use Simplex LP.
  7. 7
    Run Solver
    Click Solve. Solver iterates to find the optimal solution. If successful, choose 'Keep Solver Solution' and optionally save a Scenario.
  8. 8
    Interpret results
    If Solver found a solution, your variable cells now show the optimal values and the objective cell shows the optimal result. If not, Solver reports why (infeasible, unbounded, etc.).
  9. 9
    Generate reports
    In the Solver Results dialog, select Answer, Sensitivity, or Limits reports. The Answer Report shows original vs. final values and which constraints are binding.

⭐ Pro Tips

💡
Integer and Binary Constraints
Mark variables with 'int' when quantities must be whole numbers (e.g., number of employees). Use binary ('bin') for yes/no decisions (1=yes, 0=no).
⚠️
Non-negativity
Always add non-negativity constraints (variable cells >= 0) unless negative values make sense for your problem.
ℹ️
Sensitivity Report
Use the Sensitivity Report to see how much the optimal solution changes if constraints shift (shadow prices). If Solver fails, ensure all cells are numeric.

⚠️ Common Mistakes

  • Forgetting non-negativity
    Solver assigns negative values to components like production amounts.
    Fix: add constraint: variable cells >= 0.
  • Objective cell not linked
    Solver changes variables but the objective result doesn't change.
    Fix: verify formulas properly reference the variable cells.
  • Too many constraints
    Problem becomes infeasible and Solver finds no solution.
    Fix: relax one constraint at a time to find the conflict.
  • Wrong solving method
    Using GRG Nonlinear for a linear model makes it slower and may miss the global optimum.
    Fix: use Simplex LP for purely linear models.
