Conditional Formatting

Beginner ⏱ 5 min read

Highlight important data automatically and instantly spot trends using Conditional Formatting rules.

💡 What It Is & Why It Matters

Conditional Formatting allows you to change the appearance of cells automatically based on their values. It is essential for building dashboards, identifying errors, and calling attention to outliers in your data sets quickly.

📋 Before You Start

  • Have a dataset with values you want to visually separate or analyze.
  • Understand absolute vs relative references if you plan to use custom formula rules.

🚀 Step-by-Step

  1. 1
    Select your range
    Select the cells you want to format. You can select a single column, a row, or a multi-column range.
  2. 2
    Open Conditional Formatting
    Go to Home → Conditional Formatting. You'll see a menu with several rule types.
  3. 3
    Highlight Cell Rules
    Choose Highlight Cells Rules for basic conditions: Greater Than, Less Than, Between, Equal To, Duplicate Values, etc. Pick a condition, enter the value, choose a color style.
  4. 4
    Top/Bottom Rules
    Use Top/Bottom Rules to highlight the top 10 items, bottom 10%, or above/below average automatically.
  5. 5
    Data Bars
    Choose Data Bars to add colored bars inside each cell proportional to the value — great for quick comparison without a chart.
  6. 6
    Color Scales
    Choose Color Scales to apply a gradient (e.g., red-yellow-green) across a range based on value magnitude.
  7. 7
    Icon Sets
    Choose Icon Sets to display traffic lights, arrows, stars, or flags based on value thresholds.
  8. 8
    Use a formula for custom rules
    Choose New Rule → Use a formula. Enter a formula like =$B2>100 to highlight entire rows based on a condition. CRITICAL: use $ on the column (=$B2) but NOT the row (not =$B$2) so it applies row by row.
  9. 9
    Manage rules
    Go to Home → Conditional Formatting → Manage Rules to see all rules, change priority order, or delete rules. Rules higher in the list take priority.

⭐ Pro Tips

💡
Row Highlighting To highlight entire rows based on one column's value, lock the column with $ in your formula: =$C2="Complete"
💡
Stop If True Use 'Stop If True' in Manage Rules to prevent lower-priority rules from overriding if a previous condition is met.
ℹ️
Heatmaps Apply color scales to heatmaps — select a table of numbers, apply a red-white-green color scale for instant analysis.
💡
Selective Icons Use icon sets with 'No Cell Icon' for some thresholds to selectively show icons only for outliers or important milestones.

⚠️ Common Mistakes

  • Missing $ in Formulas
    Missing $ on column in row-highlight formulas means only the first cell gets formatted correctly.
    Use =$A2 instead of =A2.
  • Conflicting Rules
    Conflicting rules with no priority order yield unexpected colors.
    Use Manage Rules to set the correct order and optionally check "Stop If True".
  • Applying to Large Ranges
    Applying Conditional Formatting to entire columns (like A:A) slows down the workbook.
    Apply only to your specific data range.
  • Overusing Absolute References
    Using absolute reference =$A$2 in formulas means the formula doesn't adapt as it evaluates down rows.
    Use mixed reference =$A2.
